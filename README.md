# פרודוקציה 2 — רואה חשבון

כלי סטטי (קובץ HTML אחד) לחישוב עמלות סוכני משנה ויתרת עמלת ד.נ.ר (בעלים) מקבצי העמלות של מגדל וכלל.

- נתיב: `https://dnr.dani-bot.co.il/accountant/`
- עיבוד בדפדפן בלבד (SheetJS), אין שרת ואין שמירת קבצים.
- **לא לשמור כאן קבצי נתונים** — הריפו ציבורי.

## חישובים
- **חישוב 1** — סה"כ עמלת בעלים − סה"כ עמלות כל הסוכנים = יתרת עמלה לדנר.
- **חישוב 2** — פרמיה נמדדת של סוכן × אחוז עמלת הבעלים במוצר (לפי מספר בסיס זיכוי) − עמלת הסוכן.

## חברות נתמכות
- **מגדל** — לשונית בעלים + לשונית סוכני משנה. שורות של אותו סוכן/בסיס/שנה/פרמיה מאוחדות (פרמיה פעם אחת, עמלות מסוכמות).
- **כלל** — זכאות מצטברת (שנה נוכחית), שינויים בזכאות (השתנות מחודש קודם), התחשבנות ש"ק (שנים קודמות), סיכום עמלות (בדיקת התאמה).
